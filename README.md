# The Plug

The Plug is a full-stack e-commerce web application developed as part of a Software Engineering and Testing project.

The platform is designed for selling limited-edition sneakers and clothing, providing users with product browsing, searching, filtering, shopping cart functionality and checkout.

## Features

### User Features

- User registration and login
- Secure password handling
- Product browsing
- Product search and filtering
- Product details and variants
- Shopping cart management
- Checkout and order processing
- Order history
- Product reviews and ratings

### Admin Features

- Admin authentication
- Product management
- Product creation, editing and deletion
- Order management
- Discount management

## Technologies

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
