# The Plug

The Plug is a full-stack e-commerce web application developed as part of a Software Engineering and Testing project.

The platform is designed for selling limited-edition sneakers and clothing, providing users with product browsing, searching, filtering, shopping cart functionality and checkout.

## Features

### User Features

- User registration and login
- Secure password handling
- Product browsing
- Product search and filtering
- Product details and variants
- Shopping cart management
- Checkout and order processing
- Order history
- Product reviews and ratings

### Admin Features

- Admin authentication
- Product management
- Product creation, editing and deletion
- Order management
- Discount management

## Technologies

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript

## Project Structure

```text
The-Plug/
├── classes/       # Application classes
├── css/           # Stylesheets
├── data/          # Database files
├── images/        # Project images and assets
├── includes/      # Shared PHP components
├── js/            # JavaScript
├── public/        # Public application pages
└── src/           # Configuration and application logic
```
##Database
The application uses MySQL for persistent data storage, including users, products, carts, orders, payments, reviews and discounts.
The database structure is provided in the data/ directory.
##Testing
Testing was carried out across several areas of the application, including:
- Unit testing
- UI testing
- Requirements testing
- Black-box testing
- Equivalence partitioning
- Basis path testing
- Validation testing
Test scripts and related testing work are included within the project.
